# Antigravity CLI (agy) tree ownership

This tree is the opt-in second runtime from
[ADR-025](../docs/decisions/ADR-025-antigravity-second-runtime.md). Most of it
is generated by `tooling/generate/registry_sync.py` from the canonical sources
(`skills/`, `references/`, `claude/`). Edit those sources and run
`python3 tooling/generate/registry_sync.py`, never the generated files.
`python3 tooling/generate/registry_sync.py --check` flags drift and any extra
file under the generated subtrees, which is why this README sits at the
`antigravity/` root.

| Source in this tree | Installed path (under `~/.gemini`) | Owner |
| --- | --- | --- |
| `skills/<name>/SKILL.md` | `config/skills/<name>/SKILL.md` | Generated; real directories (agy does not load symlinks); optional skills install only when selected |
| `agents/b-*.md` | `config/agents/b-*.md` | Generated; read-only specialists and the `b-worker` writer profile |
| `rules/b-agentic.md` | `config/rules/b-agentic.md` | Generated kernel as an `always_on` rule; routing lines for unselected optional skills are filtered out |
| `configs/hooks.template.json` | group `b-agentic` in `config/hooks.json` | Generated template; the installer writes absolute Bun and script paths |
| `configs/mcp.template.json` | servers in `config/mcp_config.json` | Generated template; `excalidraw`, `drawio`, and `notion` install only when selected |
| `configs/settings.template.json` | `permissions` in `antigravity-cli/settings.json` | Generated template; only missing rules are added |
| `hooks/b-agy-hook.mjs` | `config/b-agentic/hooks/b-agy-hook.mjs` | Hand-written Bun adapter that reuses the pure exports of the `claude/hooks` scripts |
| none (copied from `claude/`) | `config/b-agentic/bin/`, `config/b-agentic/hooks/`, `config/b-agentic/references/` | Claude sources, copied as is (the Claude status line script is skipped) |

The installer (`tooling/install/antigravity_install.py`, reached through
`./install.sh --runtime=antigravity`) records everything it owns in
`config/b-agentic/install.json`, backs up each user file it changes under
`config/b-agentic/backups/`, and leaves every other hook group, MCP server,
setting, and permission rule alone. See the
[install runbook](../docs/runbooks/install-antigravity.md).
