# Architecture

As-built structure and diagrams from `b-drawio` or `b-excalidraw`. It describes
how the system is built today.

## Naming

`<area>.md`. A diagram shares its basename, as `<area>.drawio` or
`<area>.excalidraw`.

## Template

Scope, Components, Flow/diagram, Ownership and boundaries, Related ADRs.

## Rules

- Describe the current state and leave the reasons to the linked ADRs.
