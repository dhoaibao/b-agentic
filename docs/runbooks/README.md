# Runbooks

Guides to set up or operate the project. They hold steps a person follows, not
the reasons behind a design.

## Naming

`<verb>-<object>.md`, for example `setup-local-env.md`.

## Template

Purpose, Prerequisites, numbered Steps, Verify, Troubleshooting.

## Rules

- Commands must be runnable as written.
- End the steps with a Verify step that shows the expected result.
