# OpenCode configuration ownership

Everything in this folder is generated by `python3 tooling/generate/registry_sync.py`
from `references/mcp_operations.yaml`, `references/runtimes.yaml` (the `opencode` entry), and
`claude/configs/mcp.base.json`. Edit the sources and regenerate, never these files
([ADR-019](../../docs/decisions/ADR-019-opencode-second-runtime.md)).

| Source file             | Installed path (default `~/.config/opencode`)                | Owner                                                                                                                                                                                                                                                                                         |
| ----------------------- | ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `opencode.template.json` | `opencode.json` (`permissions`, `mcp.servers`, `experimental.todo`) | The installer merges it without replacing yours. The managed `permissions` rules are always the final block, so the last match wins; each rule is recorded by exact value. MCP servers you already have are kept and reported, and `excalidraw` and `drawio` install only when selected. `experimental.todo` is set only when you had not set it. |

Because the managed block is always last, its allow and ask rules for MCP tools and `external_directory` override an
earlier rule of yours for the same action. To keep a stricter rule, put it in OpenCode's top-level `policies` list, which
can only turn an allow or ask into a deny.

The sibling generated folders are `../skills`, `../commands`, `../agents`, and `../kernel.md`
(the block merged into `~/.config/opencode/AGENTS.md`). `../plugins/b-agentic.js` and
`../guard.mjs` are hand-written source, not generated: `guard.mjs` is the plain core reused by
`tests/opencode/guard-cases.mjs`, and the plugin wires it to OpenCode events.

The installer (`tooling/install/opencode_install.py`, reached as
`./install.sh --runtime=opencode|both`) records everything it owns in
`~/.config/opencode/b-agentic/install.json`, backs up each user file it changes under
`b-agentic/backups/`, keeps files you modified, refuses a symlinked managed directory and an
`opencode.jsonc`, adopts an earlier schema-1 manifest, and never touches `~/.claude`,
`~/.claude.json`, or `~/.pi`. It supports only the default `~/.config/opencode` directory.
Restart OpenCode after an install.
