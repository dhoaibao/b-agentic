# Pi configuration ownership

Everything in this folder is generated by `python3 tooling/generate/registry_sync.py`
from `references/mcp_operations.yaml`, `references/runtimes.yaml` (the `pi` entry), and
`claude/configs/mcp.base.json`. Edit the sources and regenerate, never these files
([ADR-011](../../docs/decisions/ADR-011-pi-second-runtime.md)).

| Source file | Installed path (default `~/.pi/agent`) | Owner |
| --- | --- | --- |
| `permission.json` | `extensions/pi-permission-system/config.json`; a copy at `b-agentic/permission.json` | `@gotgenes/pi-permission-system`. Written only when no config exists or the file is one b-agentic wrote (recorded by sha256). A config holding your own rules is left untouched with a warning; merge the copy by hand. The last matching rule wins, so deny rules come last |
| `mcp.base.json` | `mcp.json` | Pi's built-in MCP. Server entries are merged without replacing yours; each carries an `exposure` (`direct` or `deferred`) because the default `codemode` leaves tools out of the model's direct list. `excalidraw` and `drawio` install only when selected |
| `settings.packages.json` | `settings.json` (`packages`) | Pi. Three pinned entries (`pi-subagents`, `@gotgenes/pi-permission-system`, `@juicesharp/rpiv-ask-user-question`) are added when absent; a different entry of yours is kept and reported. Pi installs them on its next online start |

The sibling generated folders are `../skills`, `../prompts`, `../agents`, and `../kernel.md`
(the block merged into `~/.pi/agent/AGENTS.md`). `../extensions/b-agentic/` is hand-written
source, not generated: `guard.mjs` is the plain-Node core reused by `tests/pi/guard-cases.mjs`
and `index.ts` wires it to Pi events.

The installer (`tooling/install/pi_install.py`, reached as `./install.sh --runtime=pi|both`)
records everything it owns in `~/.pi/agent/b-agentic/install.json`, backs up each user file it
changes under `b-agentic/backups/`, keeps files you modified, refuses a symlinked managed
directory, and never touches `~/.claude` or `~/.claude.json`. It supports only the default
`~/.pi/agent` directory. Restart Pi after an install.
